# 公网部署指南（不依赖企微 / WorkBuddy，全国店端用手机浏览器即可查）

> 适用场景：你不想走企业微信，希望**任何人在任何手机浏览器（含微信内置）打开一个网址就能查激励**。
> 好消息：**查询代码（app.py + index.html + data/）已经是一个完整网站，零改动就能上公网**，所有平台通用。

---

## 一、先把"公网"这件事说清楚

你现在的查询应用，本地已经能跑（浏览器开 `http://127.0.0.1:3000` 就能查）。
所谓"上公网"，本质就是三件事：

1. 把这套代码放到一台**连着互联网、常年开机的电脑（云服务器 / 云平台）**上；
2. 给它一个**公开的网址（域名）**；
3. 让这个网址走 **HTTPS（带小锁头）**，店端手机打开才安全。

做完上面三步，你把网址发到店端群，谁点开谁就能查——**不需要 WorkBuddy、不需要企微、不限人数**。

代码的隐私保护已经就位：**完整明细只在服务端、身份证只在后台比对、查询有留痕、页面无导出**。所以搬上公网，安全底线不会塌。

## 三、路线 A：Render 免费版（零成本，约 30 分钟）

1. **注册**：打开 [render.com](https://render.com)，用 GitHub 账号登录最方便（没有就注册一个）。
2. **上传代码**：把本目录（`incentive-query` 整个文件夹）推到 GitHub 仓库；或在 Render 建 Web Service 时直接 "Upload Files"。
3. **新建服务**：Dashboard → New → **Web Service** → 选你的仓库。
   - Environment：**Python 3**
   - Build Command：`pip install -r requirements.txt`
   - Start Command：`python app.py`
   - （这些已写在 `render.yaml` / `Procfile` 里，Render 会自动识别，基本不用手填）
4. **部署**：点 Create Web Service，等几分钟，得到一个地址形如 `https://你的应用名.onrender.com`。
5. **换真实数据**：用 `data/激励明细模板.xlsx` 填好当月三张表 → 整列粘贴进 `data/incentive_sample.xlsx` 对应 Sheet、补「月份」列 → 重新部署（地址不变）。

> ⚠️ Render 免费版注意两点：① 国内访问偶尔偏慢；② 服务闲置后**第一次打开会"冷启动"等约 10–30 秒**，属正常现象，之后就快了。若介意，直接走路线 B。

## 四、路线 B：国内轻量云（正式全国铺开，约 1–2 小时 + 备案周期）

以**腾讯云轻量应用服务器**为例（阿里云同理）：

1. **买服务器**：腾讯云 → 轻量应用服务器 → 选 2 核 2G（约 ¥60–100/月）→ 系统选 Ubuntu 22.04。
2. **买域名 + 备案**：国内**必须 ICP 备案**才能用域名访问（约 1–2 周，腾讯云后台有"备案"引导，按步骤填即可）。这是国内部署绕不过的一步。
3. **SSL 证书**：腾讯云申请**免费 SSL 证书**，用于开启 HTTPS（手机上查身份证/金额必须加密）。
4. **连上服务器**：用 SSH 工具连进去（腾讯云控制台有"登录"按钮，不用装软件）。
5. **传代码 + 装环境**：
   ```bash
   # 服务器上
   sudo apt update && sudo apt install -y python3 python3-pip
   # 把本地 incentive-query 目录传上去（可用 scp，或 git clone）
   pip3 install -r requirements.txt
   ```
6. **让服务常驻**：用 `systemd` 或简单后台运行，确保 24 小时在线：
   ```bash
   nohup python3 app.py > app.log 2>&1 &
   ```
7. **配 Nginx 反代 + HTTPS**：把域名指到服务器，用 Nginx 把 443（HTTPS）转发到应用端口，启用 SSL 证书。
8. 手机浏览器打开 `https://你的域名` 即可查。

## 五、上线前必做 4 件事

1. **换真实数据**：把 `data/incentive_sample.xlsx` 替换为真实某月明细（现在跑的是示例数据）。
2. **必须 HTTPS**：没有小锁头，手机传输的身份证后几位和金额等于明文，绝不可省。
3. **建议加"月度查询口令"**（可选增强）：链接万一被转发到无关的人，加一个统一下发的月度暗号（店端查询时先填口令），能防乱查、防扒数据。需要我给 `app.py` 加这段逻辑，说一声。
4. **留痕已在**：定期打开 `data/query_log.csv` 看"谁、何时、查几次、合计多少"，审计用。

## 六、一个必须提醒的坑：微信里打开

店端大概率在**微信里点链接**。两点要注意：
- 微信内置浏览器对**未备案域名 / 被标记的域名**可能弹"已停止访问该网页"。→ 国内部署务必**备案 + 正规域名**。
- 国外免费域名（如 `.onrender.com`）在微信里偶尔被拦。→ 页面里加一句"如打不开，点右上角 ⋮ 选『在浏览器打开』"。
