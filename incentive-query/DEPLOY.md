## 方案2：公网链接（店端用普通手机/微信浏览器即可查）
> 本沙箱的"发布为应用"只产出 WorkBuddy 内部链接，**给不了真公网**。
> 真公网必须把服务端放到一个对公网开放的主机。代码已就绪（`app.py` 单文件、纯标准库可跑、读 xlsx/csv、按 PORT 环境变量监听），换地方部署改动极小。

### 路径 A：公网云 / 免费 PaaS（推荐先试，最快）
任选其一，把本目录整个传上去：

**Render（免费额度，最省事）**
1. 注册 render.com，新建 Web Service，连 Git 仓库（或手动上传目录）。
2. Build Command：`pip install -r requirements.txt`（openpyxl 可选，缺失会自动回退 CSV）
3. Start Command：`python app.py`
4. 环境变量：`PORT` 由平台自动注入（代码已支持）。
5. 部署完得到 `xxx.onrender.com`，把 `data/incentive_sample.xlsx` 换成真实数据即可。

**Vercel / 阿里云 FC / 腾讯云 SCF / 任意云服务器**
- 同样是：装依赖 → `python app.py` → 平台注入 `PORT`。
- 静态前端 `index.html` 与后端 `app.py` 同目录，无需额外配置。

### 路径 B：企业微信 H5（最贴合店端场景 · 推荐全国铺开）
把 `app.py` + `index.html` + `data/` + `public/` **整目录**部署到**任意一个 HTTPS 公网域名**（部署方式见路径 A，Render 免费额度即可）。

然后在企微管理后台配置（需管理员权限）：
1. **创建自建应用**：应用管理 → 自建 → 创建应用，取名「激励金额自助查询」。
2. **设置应用主页**：把「主页」填为你的公网地址（如 `https://你的域名/`）。
3. **可信域名校验**：应用管理 → 该应用 → 网页授权及 JS-SDK → 设置可信域名，填你的域名。
   - 下载微信给的校验文件（形如 `WW_verify_xxxxxxxx.txt`），**放进本项目的 `public/` 目录**后重新部署，后端会自动按根路径 `https://你的域名/WW_verify_xxxxxxxx.txt` 提供该文件，完成校验。
4. **可见范围**：把全国经销商店端同事 / 对应部门加进应用可见范围。
5. 店端在企微工作台点开应用即可查询，7×24 可用。

> 说明：`index.html` 即 H5 页面，无需改代码；可信域名校验文件机制已内置（`app.py` 的 `public/` 处理），你只需把微信下发的校验文件丢进 `public/` 重启 / 重部署即可。

## 数据安全要点（对外必须保留）
- 完整明细表只在服务端，前端只回传"本人/本店"对应的行。
- 身份证完整号只在服务端比对，页面不显示完整号码（门店查询给掩码便于核对）。
- 每次查询写入 `data/query_log.csv` 留痕：时间/方式/查询人/钥匙(掩码)/月份/是否查到/条数/合计/该键累计第几次。
- 查询页无导出/打印功能（打印样式下整页隐藏），店端无法导出他人数据。
- 查不到统一提示"联系渠道赋能科核对"，不暴露有无此人。
