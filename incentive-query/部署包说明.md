# 激励金额自助查询 · 企微 H5 部署包说明

本目录就是一个**可直接上传部署的完整包**，无需改代码即可挂到企业微信，让全国店端在企微工作台点开即查。

## 一、包里有什么（文件清单）

| 文件 / 目录 | 作用 |
|---|---|
| `app.py` | 后端（纯标准库 + 可选 openpyxl，按 `PORT` 监听，含企微可信域名校验文件机制） |
| `index.html` | 前端查询页（即 H5 页面，移动端已适配，无导出/打印） |
| `requirements.txt` | 依赖：`openpyxl`（缺失会自动回退 CSV，建议保留） |
| `data/` | 数据目录：`incentive_sample.xlsx`（示例数据，三 Sheet）、`激励明细模板.xlsx`（每月填表用）、`query_log.csv`（留痕，运行后自动生成） |
| `public/` | 放企微下发的可信域名校验文件 `WW_verify_xxxx.txt`（放进去重部署即生效） |
| `render.yaml` | Render 一键部署蓝图（免费额度可用） |
| `Procfile` | 通用启动命令（Render / Heroku 风格） |
| `企微部署跟着点一遍.md` | 从零到上线的分步点击指引（见本目录同名文件） |

## 二、本地先跑一遍（可选，验证用）

```bash
pip install -r requirements.txt
python app.py            # 默认监听 3000，可用 PORT 环境变量改端口
# 浏览器打开 http://127.0.0.1:3000/ 即可查询
```

## 三、部署到公网（推荐 Render 免费）

1. 把本目录整个上传到 GitHub 仓库（或 Render 创建时直接 Upload Files）。
2. Render 新建 Web Service → 选仓库 → 运行时 Python 3。
3. Build Command：`pip install -r requirements.txt`；Start Command：`python app.py`（已写在 `render.yaml`，自动识别）。
4. 部署完成得到 `https://xxxx.onrender.com`，浏览器打开应看到查询页，`/healthz` 返回 `{"ok":true}`。

> 用其他平台（阿里云/腾讯云/任意云服务器）同理：装依赖 → `python app.py` → 平台注入 `PORT` → 反代到 HTTPS 443。

## 四、换数据（每月一次）

用 `data/激励明细模板.xlsx` 填好当月三张表 → 整列粘贴进 `data/incentive_sample.xlsx` 对应 Sheet、补「月份」列 → 重新部署（链接/域名不变）。

## 五、企微可信域名校验文件

企微后台「设置可信域名」时会给你一个 `WW_verify_xxxxxxxx.txt`：
- 把它放进本包的 `public/` 目录；
- 重新部署（Render 会自动重新构建）；
- 验证 `https://你的域名/WW_verify_xxxxxxxx.txt` 能直接打开即完成校验（`app.py` 已内置此机制）。

## 六、安全要点（对外必须保留）

- 完整明细只在服务端，前端只回传"本人/本店"对应行；
- 身份证完整号只在服务端比对，页面只显示掩码；
- 每次查询写入 `data/query_log.csv` 留痕（谁/何时/查几次/金额）；
- 查询页无导出/打印，店端无法带走上他人数据。
