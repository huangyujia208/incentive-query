# 企微 H5 部署 · 跟着点一遍

> 目标：把"激励金额自助查询"挂到企业微信，全国店端在企微工作台点开即查。
> 适用：你（或企微管理员）有「自建应用」配置权限即可。全程**零代码改动**，只点界面。
> 说明：本指引里的实际点击动作需由你/管理员在企微后台完成；我这边已把代码包、校验文件机制、部署配置全部备好，照着点就能跑通。

---

## 前置准备（二选一拿到公网地址）

- **A｜Render 免费额度（推荐小白）**：注册 render.com 即可，无需信用卡。
- **B｜自有云服务器 / 其他 PaaS**：阿里云、腾讯云、Vercel 等，只要有公网 HTTPS 域名。

下面以 **A（Render）** 为主线，B 只差"上传代码 + 反代 HTTPS"这一步。

---

## 第一段：把代码部署到公网（以 Render 为例）

1. 打开 [render.com](https://render.com) 注册 / 登录。
2. 把本部署包整个目录推到 GitHub 仓库（或 Render 创建服务时选 **Upload Files** 直接传）。
3. 在 Render 点 **New → Web Service**，选刚才的仓库。
4. 配置（其实 `render.yaml` 已写好，这里核对一眼）：
   - **Runtime**：Python 3
   - **Build Command**：`pip install -r requirements.txt`
   - **Start Command**：`python app.py`
   - **Plan**：Free（免费额度足够店端查询量）
5. 点 **Create Web Service**，等 1–2 分钟构建完成。
6. 得到地址形如 `https://incentive-query-xxx.onrender.com`。
7. **先验证**：浏览器打开 `https://你的域名/` 应看到查询页；再开 `https://你的域名/healthz` 应返回 `{"ok":true,...}`。

> 若用云服务器：把包传上去 → `pip install -r requirements.txt` → `python app.py` → 用 Nginx/Caddy 把 80/443 反代到 `http://127.0.0.1:3000` 并配 HTTPS 证书。

---

## 第二段：企微后台配置（核心，一步步点）

1. 打开 [work.weixin.qq.com](https://work.weixin.qq.com) 并登录（需有企微管理员或自建应用权限）。
2. 左侧 **应用管理 → 自建 → 创建应用**。
   - 应用名称填：`激励金额自助查询`
   - 上传一个 logo（可选）
   - **可见范围**：选「全国经销商店端」对应的部门 / 标签（决定哪些人能在工作台看到它）
3. 进入刚建的应用，找到 **主页** 一栏，填：`https://你的域名/`（第一段拿到的地址，结尾带 `/`）。
4. **可信域名校验**（企微硬性要求）：
   - 同应用页面 → **网页授权及 JS-SDK → 设置可信域名** → 填 `你的域名`（**不带 https://**）。
   - 企微会提示下载一个文件，形如 `WW_verify_xxxxxxxx.txt`。
   - 把这个文件放进本部署包的 `public/` 目录，然后**重新部署** Render（代码不变，Render 会自动重新构建，让文件生效）。
   - 验证：浏览器打开 `https://你的域名/WW_verify_xxxxxxxx.txt`，能看到文件内容即校验通过。
5. 点 **保存**。

> 小提示：如果你的企微版本里"可信域名"在「应用 → 开发者接口」或「企业设置 → 可信域名」里，位置名称可能略有差异，但都要求"域名根路径下能访问到那个校验文件"——本包已满足。

---

## 第三段：店端怎么用

- 店端同事打开**企业微信 → 工作台 → 找到「激励金额自助查询」**，点开即进入查询页。
- 输入**店代码**查本店三类激励，或输入**18 位身份证**查本人全部（含店长查终端激励）。
- 详细图文见 `店端使用教程.html`。

---

## 第四段：每月更新数据

1. 用 `data/激励明细模板.xlsx` 填好当月三张表（试驾 / 交付 / 终端），整列粘贴进 `data/incentive_sample.xlsx` 对应 Sheet，补「月份」列。
2. 重新部署（Render 重新构建一次，或云服务器替换文件后重启 `python app.py`）。
3. 域名 / 企微入口不变，店端无需任何操作。

---

## 常见问题

- **企微提示"可信域名校验失败"**：确认 `WW_verify_xxxx.txt` 已放进 `public/` 且**已重新部署**；直接访问 `https://你的域名/WW_verify_xxxx.txt` 能看到内容才算生效。
- **主页打开空白 / 404**：确认 Render 服务已 Running、第一段第 7 步验证通过；主页 URL 结尾带 `/`。
- **身份证查不到**：确认 `incentive_sample.xlsx` 已替换为真实数据，且身份证号与原表完全一致（含大小写 X）。
- **查某店没结果**：先核对店代码（试驾=经销商编码 / 交付=经销商代码 / 终端=店编号）是否一致；仍无则联系渠道赋能科核对。

## 留痕怎么看

每次查询自动写入 `data/query_log.csv`：时间 / 方式 / 店代码或掩码身份证 / 查询人 / 月份 / 是否查到 / 条数 / 合计 / 该键累计第几次。用 Excel 打开即可审计"谁、何时、查了几次"。
