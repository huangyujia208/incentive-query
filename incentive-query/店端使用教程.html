激励金额自助查询 · 使用指引

店端同事看这一页就够了｜输入店代码或身份证，一次查回试驾 / 交付 / 终端三类激励

一在哪查？

1
【全国店端主路径】企业微信 → 工作台 → 打开应用

在企微工作台找到「激励金额自助查询」应用，点开即是查询页（H5 页面）。不用记链接、不用复制，这是覆盖全国店端的正式入口。

2
【备选，仅限 WorkBuddy 用户】在 WorkBuddy 内打开分享链接

这条路径只对在 WorkBuddy 里登录了账号的人开放。下面按"完全没用过 WorkBuddy"的小白视角，一步步来：

  1. 先确认你有 WorkBuddy 账号并登录。如果还没有，找你们对接人 / IT / 渠道赋能科开通一个（这个查询应用只对 WorkBuddy 内的人开放）。
  2. 拿到链接。链接由渠道赋能科发给你——可能是聊天里的一条"应用链接"消息，也可能是 WorkBuddy 里「我发布的应用 / 应用中心」里的一个应用卡片。
  3. 在 WorkBuddy 里点开它（关键：别去外部浏览器）。
    • 方式A（推荐）：在 WorkBuddy 的对话框里直接点击那条链接，系统会用 WorkBuddy 内置浏览器打开查询页。
    • 方式B：进入 WorkBuddy「设置 → 数据管理 → 我发布的应用」（或你们版本里的「应用中心」），找到「激励金额自助查询」点开。
  4. 页面打开后，按下面"怎么查"一节，输入店代码或身份证即可。

⚠️ 此方式仅限已登录 WorkBuddy 的用户；店端同事若不使用 WorkBuddy，请走上面的企微工作台入口。

🚫 小白最常踩的 3 个坑：
  • 复制到 Chrome / 微信 / Safari 去开 → 会显示"链接不完整"。这是平台安全限制，不是坏了，请回到 WorkBuddy 里点开。
  • 只复制了一半链接 / 手敲链接 → 链接是一整段、带访问参数，少一段就打不开。
  • 把链接贴进「新建任务」输入框 → 那只是给 AI 发了一段文字，不会打开应用，也不会触发查询。
⚠️ 误区提醒：把链接贴进「新建任务」对话框，只是给 AI 发了一段文字，不会打开查询应用。外部浏览器（Chrome / 微信内置 / Safari）直接打开也会提示"链接不完整"——请用企微工作台入口或WorkBuddy 内打开。

二怎么查？两种钥匙，一个框

1
查本店全部激励 → 输入店代码

如 GZ001，系统自动匹配三类激励（试驾的经销商编码、交付的经销商代码、终端的店编号），一次出本店三类结果。

2
查本人全部激励 → 输入 18 位身份证号

系统自动匹配试驾 / 交付的身份证，以及终端激励的总经理身份证。店长用自己的身份证也能查到门店的终端激励。

3
月份选填

留空 = 查全部月份；填 2026-09 只查当月。

✅ 结果按「试驾 / 交付 / 终端」三类分组，每类列出明细 + 小计，页面顶部显示全部合计金额。

三注意事项

  • 隐私保护：身份证号只在后台做比对，页面上不显示完整号码（门店查询仅显示前4+****+后4的掩码）。
  • 只查不导出：本页面没有导出 / 打印功能，数据仅供本人 / 本店核对使用，请妥善保管查询结果。
  • 查不到怎么办：先核对钥匙是否填对（店代码 / 18 位身份证）；仍查不到，说明本月可能无对应记录，请联系渠道赋能科核对，不要反复尝试猜钥匙。
  • 留痕说明：每次查询都记录在案（谁、何时、查了几次），请放心核对、正常使用。
📌 一句话记住：复制整段链接打开 → 一框输入店代码或身份证 → 三类激励一次出。
